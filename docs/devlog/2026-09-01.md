# Devlog 01 September 2026 — Produksi VPS (T09, T10, D1-D4, T26, T11)

## Ringkasan Eksekusi Hari Ini
Sesi hari ini menandai transisi penuh proyek SIAGA dari fase pembangunan lokal (*local-first*) menuju infrastruktur server produksi sesungguhnya di Cloud VPS (CloudBaik, Ubuntu 24.04 LTS).

### 1. T09 — Eksplorasi Kondisi Awal & Hardening VPS
- **Spesifikasi Server:** Ubuntu 24.04.2 LTS (Noble Numbat), Kernel `6.8.0-63-generic x86_64`, 4 vCPU Intel Core (Broadwell, 2.0 GHz), 3.8 GiB RAM, 19 GiB SSD.
- **SSH Key-Based Only:**
  - Keypair ed25519 baru dibuat khusus untuk VPS (`~/.ssh/id_ed25519_siaga`).
  - User non-root `siaga` dibuat dengan grup `sudo`.
  - Drop-in `/etc/ssh/sshd_config.d/00-siaga-hardening.conf` dipasang (`PermitRootLogin no`, `PasswordAuthentication no`, `PubkeyAuthentication yes`, `MaxAuthTries 3`).
  - Akun root di-lock (`passwd -l root`), kredensial password awal di `VPS.txt` di-redact.
- **Firewall UFW:**
  - Default `DENY incoming`, `ALLOW outgoing`.
  - Port yang dibuka **hanya 4422/tcp** (SSH).
  - Port internal (18789 untuk OpenClaw Gateway dan 8000 untuk Dashboard API) terisolasi ketat di loopback `127.0.0.1` dan dilindungi oleh firewall drop policy.
- **Fail2ban & Unattended Upgrades:** Aktif memantau port 4422 dengan backend `systemd`.
