### 1. Tugas 0: Perbaikan Integritas Metrik `/api/metrics` (Kepatuhan CLAUDE.md #2)
* **Masalah:** Endpoint `/api/metrics` sebelumnya memuat nilai statis (hardcoded) yang menyalin angka ilustratif dari rencana (misalnya `avg_lead_time_hours: 31.0`). Hal ini berisiko menyamarkan hasil evaluasi model yang sesungguhnya.
* **Solusi:**
  1. Metrik evaluasi model AI (`precision_pct`, `recall_pct`, `f1_score`, `eval_timestamp`) kini dibaca secara dinamis dari berkas `data/eval_results.json` hasil eksekusi nyata `scripts/run_eval.py`.
  2. Jika berkas evaluasi belum tersedia, sistem mengembalikan nilai `null` dengan flag `"metrics_available": false` dan status `"uncalibrated"`, bukan mengarang angka contoh.
  3. Metrik *Lead Time* dihitung dari selisih waktu nyata antara `first_seen` dan `blacklist_listed_at` pada tabel `domain_findings`. Jika belum ada domain terdeteksi yang kemudian masuk feed publik, sistem secara jujur mengembalikan `null` dengan catatan `"belum cukup data"`.
  4. Status kalibrasi diturunkan secara dinamis dari tanggal evaluasi terakhir: `"calibrated (YYYY-MM-DD)"`.

### 2. Tugas D2 & D3: Dashboard UI Statis & Grafik Tren Inline SVG
* **Vanilla Stack Tanpa Build Step:** Dibangun menggunakan HTML5, CSS3, dan Vanilla JavaScript murni tanpa build tool (tanpa npm, webpack, atau Vite) sehingga deployment ke VPS Linux cukup dengan menyalin direktori `dashboard/static/`.
* **Zero External CDN Dependencies (100% Offline-Ready):** Tidak ada skrip eksternal (tanpa Chart.js, D3.js, atau CDN font) sehingga tampilan dashboard tahan terhadap kegagalan jaringan saat perekaman video presentasi.
* **Grafik Inline SVG:** Komponen grafik tren 14 hari dan visualisasi efisiensi penyaringan bertingkat (*funnel ratio bars*) digambar langsung secara matematis via elemen `<svg>` inline (~35 baris JavaScript).
* **Kepatuhan Privasi & UU PDP (Default Domain Masking):** Nama domain temuan disamarkan secara otomatis di tabel UI (contoh: `p***.web.id`, `c***.shopee.co.id...`) guna mencegah potensi pencemaran nama baik (*defamation*) pada rekaman video. Disediakan toggle *Penyamaran* dengan status default **AKTIF**.

* **Pengukuran RAM Aktual:**
